    figkit 사용 가이드¶

    figkit(illustrator-figkit)은 논문에 들어갈 그림을 SVG 한 장으로 만들고 Adobe Illustrator 에서 편집 가능한 .ai 와 .pdf 로 마무리하는 도구다. Claude Code 플러그인으로 설치하고 명령 하나(make_figure.py)에 그림 설명, 원고, 데이터 가운데 하나 이상을 준다.

    무엇을 주면 무엇이 나오나¶

    입력 옵션 모델 호출
    측정 데이터(csv 와 panel.yaml) --panel 없음. 아무것도 밖으로 보내지 않는다
    유전체 지도·변이 패널 입력(GenBank, 특징 표, 스펙 yaml) --genome-panel 없음
    필요한 그림의 설명(md, txt) --brief 있음. 본인 Claude 계정으로 돈다
    원고(md, txt, pdf) --manuscript 있음

    결과는 --out 폴더에 <name>.svg, <name>.pdf, 캡션 사이드카 <name>-CAPTION.md, 실행 보고서 <name>.report.json, 근거 보고서 <name>.evidence.md 와 <name>.claims.json 으로 나온다.

    어느 경로를 쓰나¶

    경로 A 는 모델 없이 결정론으로 그린다. 같은 입력이면 같은 그림이 나온다.

    • 데이터 패널: 막대, 선, 산점, 히트맵
    • 유전체 지도와 변이 패널: 유전자 클러스터 비교, 플라스미드 지도, 유전자별 변이 지도
    • 계통수 패널: 표로 준 계통수(tree_table), Newick 과 행렬(tree_matrix)
    • 작은 도식: plan.json 으로 그리는 띠, 고리, 행렬 도식

    경로 B 는 모델이 그린다. 요청문이나 원고를 읽고 무엇을 그릴지 정한 뒤 작가 모델이 좌표를 쓰고 비평 모델이 렌더를 판정한다. 구획이 겹치는 기전도, 같은 분자가 여러 번 나오는 그림, 대사경로처럼 요소가 많은 그림이 여기에 맞다. 비용과 시간이 든다(비용과 시간).

    경계에 걸리면 경로 A 로 먼저 그린다. 그림 안 내용이 맞는지가 먼저이고 꾸밈은 Illustrator 마무리에서 한다.

    1.2.0 판에서 쓸 수 있는 것¶

    경로 A 전부(데이터 패널, 유전체 지도, 변이 패널, 표, 계통수 패널)와 경로 B 의 대사경로·유전자 클러스터 도판이다. 경로 B 의 일반 기전도는 실험 기능이다. 자세한 것은 범위와 알려진 한계에 있다.
