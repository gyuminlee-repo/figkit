    업데이트¶

    새 판은 플러그인의 version 이 오를 때만 내려온다. 커밋이 쌓여도 version 이 같으면 claude plugin update 는 아무것도 받지 않는다. 지금 판은 1.2.0 이다.

    1.2.0 부터 환경 변수 이름은 FIGKIT_ASSETS, FIGKIT_CACHE, FIGKIT_ART_CACHE, FIGKIT_CORPUS_DATA 다. 1.1.0 에서 다른 이름으로 설정했다면 새 이름으로 다시 설정한다. 옛 이름은 읽지 않는다. 기본 캐시 폴더는 ~/.cache/figkit 이다.

    업데이트는 claude plugin update 로 받거나 Claude Code 의 백그라운드 업데이트를 기다린다. 백그라운드 업데이트는 gh 자격 증명 도우미를 거쳐야 인증된다(설치).

    업데이트 뒤 할 일¶

    • Illustrator MCP 를 다시 등록한다. 플러그인 폴더 안의 node_modules 로 등록했다면 판이 바뀔 때 그 경로가 달라진다. 별도 체크아웃으로 등록했다면 할 일이 없다.
    • 점검을 다시 돌린다. /illustrator-figkit:setup 이 새 판에서도 준비가 됐는지 본다.

    판이 바뀌어도 이어지는 것¶

    플러그인 파일은 판마다 새 폴더에 놓인다. 모델 원장과 호출 기록, 경로 B 실행 폴더는 플러그인 데이터 폴더(CLAUDE_PLUGIN_DATA) 아래에 쓰므로 판이 바뀌어도 원장과 --resume 이 이어진다. 다른 곳에 두려면 FIGKIT_DATA 로 뿌리를 정한다. setup 이 만든 Python 가상환경도 같은 데이터 폴더에 있다.

    make_figure.py 의 산출물은 처음부터 작업 폴더의 out/<이름>/ 에 쓰므로 업데이트의 영향을 받지 않는다.
