    설치¶

    플러그인 설치¶

    Claude Code 세션 안에서 두 줄을 친다.

    /plugin marketplace add gyuminlee-repo/illustrator-figkit
/plugin install illustrator-figkit@illustrator-figkit

    셸에서는 다음과 같다.

    claude plugin marketplace add gyuminlee-repo/illustrator-figkit
claude plugin install illustrator-figkit@illustrator-figkit

    저장소 읽기 권한이 필요하다

    플러그인 저장소는 비공개다. /plugin marketplace add 는 이 머신의 git 을 대화형 입력 없이 부르고 이미 저장된 자격 증명만 쓴다. 저장소 읽기 권한을 받은 계정으로 둘 중 하나를 준비한다.

    • HTTPS: gh auth login 뒤 gh auth setup-git. SSH 키가 없는 머신은 CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1 을 두면 SSH 시도를 건너뛴다.
    • SSH: ssh-agent 에 올린 키와 known_hosts 에 든 github.com.

    GITHUB_TOKEN 환경 변수만으로는 백그라운드 업데이트가 인증되지 않는다. 권한이 없으면 저장소 소유자에게 요청한다.

    설치하면 세 가지가 생긴다.

    이름 하는 일
    /illustrator-figkit:setup 이 머신에서 도는지 점검한다. 빠진 Python 패키지는 확인을 받은 뒤 플러그인 데이터 폴더의 가상환경에 한 번 설치한다. Illustrator MCP 등록 절차를 OS 별로 안내한다
    /illustrator-figkit:make <요청문.md 또는 panel.yaml> make_figure.py 를 돌려 작업 폴더의 out/<이름>/ 에 그림과 보고서를 내고 안내한다
    illustrator-figure 스킬 「figure 만들어」, 「Illustrator 에서 마무리해」 같은 말에 잡힌다. 스킬로 쓰기

    점검: /illustrator-figkit:setup¶

    설치 직후 한 번 돌린다. 점검이 기본이고 설치는 확인을 받은 뒤에만 한다.

    1. 쓸 Python 을 고른다. 플러그인 데이터 폴더의 가상환경이 있으면 그것, 없으면 python3 다.
    2. bootstrap.py 로 점검한다. 종료코드 0 이면 Illustrator 없이 그림을 그리고 검수할 준비가 됐다. 1 이면 빠진 것이 화면에 찍힌다. 2 면 이 OS 에서 Illustrator 자동화를 지원하지 않는다는 뜻이고 SVG 와 PDF 는 그래도 나온다.
    3. 빠진 패키지가 있으면 무엇을 어디에 설치할지 말하고 확인을 받은 뒤 가상환경에 설치한다. 시스템 Python 은 건드리지 않는다.
    4. 경로 B 를 쓸 사람에게는 --dry-run 으로 준비물을 확인한다. 모델을 부르지 않는다.
    5. Illustrator 마무리를 쓸 사람에게는 MCP 등록 절차를 안내한다.

    Python 의존성은 세션 시작 훅으로 깔지 않는다. 매 세션 pip install 이 돌면 시작이 느려지고 네트워크가 없을 때 세션 시작이 실패하기 때문이다.

    아트 카탈로그 (경로 B)¶

    경로 B 의 작가는 Servier Medical Art 카탈로그에서 아이콘을 고른다. 카탈로그는 플러그인에 없고 한 번 받아 만든다.

    python3 mech/servier_fetch.py --assets <아트 폴더>
export FIGKIT_ASSETS=<아트 폴더>

    원천 177 개(약 11 MB)를 받아 sha256 을 대조하고 카탈로그를 굽는다. Servier 항목은 CC BY 4.0 이라 저작자 표시가 의무다. make_figure.py 가 그림이 쓴 아트의 표기문을 캡션 사이드카의 Art: 줄에 적는다.

    Illustrator MCP 등록 (마무리를 쓸 때)¶

    플러그인은 Illustrator MCP 서버를 자동으로 등록하지 않는다. 등록 명령이 OS 마다 다르기 때문이다. 먼저 이미 등록돼 있는지 본다.

    claude mcp get illustrator

    없으면 OS 에 맞게 직접 등록한다.

    • Windows, macOS: Node.js 20 이상을 설치하고 플러그인 폴더에서 npm install 을 돌린다. postinstall 이 MCP 번들 패치(scripts/patch-mcp-bundle.cjs)를 건다. 등록은 claude mcp add illustrator --scope user -- node "<플러그인 폴더>/node_modules/illustrator-mcp-server/dist/index.js" 다. 플러그인 판이 바뀌면 이 경로가 달라지므로 업데이트 뒤 다시 등록한다. 판에 묶이지 않게 하려면 별도 체크아웃에서 npm install 하고 그 경로로 등록한다.
    • WSL2: 마켓플레이스 설치본은 Windows 쪽에서 읽지 못한다. 저장소를 /mnt/<드라이브>/ 아래에 체크아웃하고 그 폴더에서 bash allow-illustrator.sh 를 돌린 뒤 claude --plugin-dir <체크아웃> 으로 세션을 연다. Illustrator 없이 SVG 와 PDF 만 낼 때는 마켓플레이스 설치본으로 충분하다.
    • macOS 첫 호출: Automation 권한을 물으면 System Settings > Privacy & Security > Automation 에서 터미널 또는 Python 의 Adobe Illustrator 제어를 허용한다.

    등록을 확인하려면 Illustrator 를 띄우고 문서 하나를 연 상태에서 새 세션에 mcp__illustrator__get_document_info 를 부른다.

    마켓플레이스 설치가 돌리는 npm install

    마켓플레이스 설치 때 Claude Code 가 스스로 npm install --ignore-scripts 를 돌린다. 이 설치는 MCP 번들 패치를 걸지 않으므로 Illustrator MCP 에 쓰지 않는다.

    체크아웃에서 직접 쓰기¶

    플러그인 없이 쓰거나 설치 전에 시험하려면 체크아웃을 받아 한 세션만 로드한다.

    gh repo clone gyuminlee-repo/illustrator-figkit
cd illustrator-figkit
python3 bootstrap.py                     # 빠진 것과 설치 명령을 찍는다
claude --plugin-dir <체크아웃 경로>       # 이 세션에만 플러그인을 로드한다

    체크아웃 안에서 claude 만 열면 스킬이 잡히지 않는다. 스킬은 플러그인 경로 skills/ 에 있기 때문이다. Illustrator 연결까지 확인하려면 python3 bootstrap.py --illustrator 를 쓴다.
