    문제 해결¶

    설치¶

    플러그인 설치가 인증 오류로 실패한다. 저장소가 비공개라 이 머신의 git 에 읽기 권한이 있는 자격 증명이 저장돼 있어야 한다. gh auth login 뒤 gh auth setup-git 을 돌린다. GITHUB_TOKEN 만으로는 백그라운드 업데이트가 인증되지 않는다.

    cairosvg 나 pypdf 가 없다는 오류가 난다. /illustrator-figkit:setup 을 먼저 돌린다.

    cairosvg 가 import 에서 실패한다. 시스템 라이브러리 cairo 가 없다. 데비안 계열은 libcairo2, macOS 는 brew install cairo 다.

    체크아웃 안에서 Claude Code 를 열었는데 스킬이 안 잡힌다. 스킬은 플러그인 경로에 있다. claude --plugin-dir <체크아웃> 으로 연다.

    claude plugin update 가 아무것도 받지 않는다. 플러그인 version 이 오르지 않았다. 새 판이 나오지 않은 것이다.

    실행¶

    종료코드 2 와 [MISSING] 줄. 빠진 준비물과 얻는 법이 그 줄에 적혀 있다. 경로 B 에서 흔한 것은 아트 카탈로그다(python3 mech/servier_fetch.py --assets <폴더> 뒤 FIGKIT_ASSETS=<폴더>).

    업데이트 뒤 아트 검사가 SKIP된다. 이전 환경 변수와 캐시는 자동 승계하지 않는다. FIGKIT_ASSETS로 아트 폴더를 다시 지정하고 python3 mech/servier_art.py --ensure <fig.yaml>로 필요한 변형을 ~/.cache/figkit/art에 생성한다. 변형 캐시를 따로 둘 때는 FIGKIT_ART_CACHE를 지정한다.

    csv 를 줬는데 그림이 없다. 짝이 되는 --panel 이 없으면 그리지 않고 템플릿을 쓴 뒤 종료코드 2 로 멈춘다. 템플릿을 채워 --panel 로 준다.

    종료코드 3. 열린 질문이 있거나 요청이 지원 장르 밖으로 읽혔다. <name>.questions.md 를 보고 --answers 로 다시 돌리거나 --accept-open 으로 그린다. 장르 밖이면 --out-of-scope-ok 다.

    도중에 멈췄다(사용 한도 등). 같은 명령에 --resume 을 붙인다.

    종료코드 0 인데 결과가 이상하다. report.json 의 status 를 본다. accepted 가 아니면 채택된 그림이 아니다. 이유는 <name>.UNRESOLVED_TODO.md 에 있다.

    한글 라벨이 □ 로 깨진다. 그림 안은 영문만 쓴다. 해석은 캡션에 둔다.

    Illustrator¶

    글자가 경고 없이 사라졌다. SVG 의 font-family 에 이름을 나열했을 가능성이 크다. Illustrator 는 글리프 단위 폴백을 하지 않는다. 이름을 하나만 쓴다.

    글꼴이 Arial 로 바뀌었다. font-family 에 공백이 든 이름("Source Sans 3")을 쓰면 Illustrator 가 해석하지 못하고 조용히 바꾼다. PostScript 이름 SourceSans3 을 쓴다. figkit/figure_lint.py 가 이것을 error 로 짚는다.

    반입한 뒤 크기나 위치를 바꾸고 싶다. 만든 뒤 옮기지 않는다. 크기는 반입 전에 파일 쪽에서 확정한다.

    PDF 를 SVG 로 바꿔 들이려 한다. 하지 않는다. Illustrator 의 SVG 내보내기가 임베드된 래스터를 별도 파일로 흩어 놓는다.

    반입한 글자가 두 배로 많다. MCP 번들 패치가 빠졌다. 플러그인 폴더에서 npm install 로 패치를 다시 걸고 같은 경로로 등록한다. 마켓플레이스가 돌린 --ignore-scripts 설치는 패치를 걸지 않는다.

    자동화 중 Illustrator 창이 최소화된다. 예전 패치가 입혀진 번들이다. node scripts/patch-mcp-bundle.cjs 를 다시 돌리면 창을 건드리지 않는 기본값이 된다.

    스크립트가 응답하지 않는다. 대화상자가 떠 있을 가능성이 크다. Illustrator 창을 앞으로 가져와 확인한다.

    WSL 에서 Illustrator 를 부르지 못한다. 마켓플레이스 설치본은 Windows 쪽에서 읽지 못한다. 저장소를 /mnt/<드라이브>/ 아래에 체크아웃하고 bash allow-illustrator.sh 를 돌린 뒤 claude --plugin-dir <체크아웃> 으로 연다.

    정리 스크립트가 거부한다. 기존 .ai 의 정리는 반입한 그룹 안에서만 돈다. 범위 파일이 없거나 비어 있으면 정리 스크립트가 실행을 거부한다. 사용자 오브젝트를 지우지 않기 위한 동작이다.

    환경 변수¶

    변수 뜻 없으면
    FIGKIT_ASSETS 아트 뿌리 플러그인 안 mech/assets
    FIGKIT_CACHE 공유 결과 캐시 ~/.cache/figkit
    FIGKIT_DATA 원장, 호출 기록, 실행 폴더의 뿌리 플러그인 데이터 폴더
    FIG_CLAUDE Claude Code CLI 실행 파일 PATH 의 claude
    FIG_MODEL 모델 이름 도구 기본값
    FIG_AUTHOR_EFFORT 작가 생각 강도 medium
    FIG_AUTHOR_MAX_OUTPUT_TOKENS 작가 응답 하나 출력 상한 32000
    FIGKIT_FONT_DIR 본문 글꼴 폴더 플러그인 안 fonts/
    FIGKIT_OFFLINE 1 이면 --offline 과 같다 조회한다
    ILLUSTRATOR_MCP_MINIMIZE 1 이면 자동화 뒤 창을 최소화 창을 건드리지 않는다
