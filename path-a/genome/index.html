    유전체 지도와 변이 패널¶

    유전체 패널 셋은 모델 없이 그린다. --genome-panel 에 종류를 주고 입력은 --genbank, --features, --genome-spec 으로 준다.

    종류 그리는 것
    cluster 유전체나 균주마다 한 트랙인 유전자 좌위 비교와 트랙 사이 상동 띠
    plasmid 특징 표에서 그린 원형 플라스미드 지도
    mutation 유전자마다 축척 막대 하나와 변이 위치·표기

    예제¶

    예제 입력은 전부 합성이다. 서열은 고정 시드의 무작위 코돈이고 유전자와 균주 이름은 자리표시자다.

    python3 make_figure.py --name cluster --out out/cluster --genome-panel cluster \
    --genome-spec examples/genome_panels/cluster.genome.yaml
python3 make_figure.py --name plasmid --out out/plasmid --genome-panel plasmid \
    --genome-spec examples/genome_panels/plasmid.genome.yaml
python3 make_figure.py --name mutation --out out/mutation --genome-panel mutation \
    --genome-spec examples/genome_panels/mutation.genome.yaml

    스펙 파일¶

    스펙(.genome.yaml)이 좌위, 유전자 분류, 상동 띠, 사건을 정한다. 위 클러스터 그림의 스펙이다.

    panel: cluster
loci:
  - {name: Strain A, genbank: strain_a.gb, breaks: [[4300, 6500]]}
  - {name: Strain B, genbank: strain_b.gb}
  - {name: Strain C, features: strain_c.csv, locus: C}
class_of: {abcA: biosynthesis, abcB: biosynthesis, abcC: biosynthesis, abcD: biosynthesis,
           regR: regulation, tnpA: mobile element}
classes: {biosynthesis: data_blue, regulation: sage_green, mobile element: strain_purple}
ribbons:
  - {between: [0, 1], source: compute}
  - {between: [1, 2], source: ribbons_bc.csv}
ribbon_min_identity: 30
events:
  - {locus: Strain B, type: deletion, start: 2850, end: 4000, label: "ΔabcD"}
  - {locus: Strain C, type: insertion, at: 3750, label: IS}
  - {locus: Strain C, type: replacement, start: 2150, end: 2900, label: kanR}
    • 좌위는 GenBank 파일(genbank)이나 특징 표(features, 1 부터 세고 양 끝 포함)로 준다.
    • 상동 띠는 서열에서 계산하거나(source: compute) 표로 준다.
    • 사건은 결실(deletion), 삽입(insertion), 치환(replacement)이다.

    --genbank 와 --features 는 여러 번 줄 수 있다. cluster 는 좌위마다 한 번씩 준다.

    요청문과 함께¶

    --brief 나 --manuscript 를 함께 주면 유전체 스펙이 경로 B 의 구조화 입력이 된다. 모델이 요청문의 표시 이름, 분류, 결실을 스펙 위에 얹은 <name>.genome_overlay.yaml 을 쓰고 작가가 그 패널을 그림 안에 배치한다. 새 특징을 지어내지 않는다.

    요청에 플라스미드 특징 표나 유전자별 변이 표를 --table 로 주면 열 모양을 보고 해당 패널로 바로 보낸다. 이 경우도 --brief 나 --manuscript 가 필요하다.
