    직접 그린 SVG 출고 (--svg)¶

    호출 LLM 이 요청문을 읽고 SVG 한 장을 직접 그리면 figkit 은 그 SVG 를 Illustrator 가 그대로 읽는 출고 형식으로 옮긴다. 이 경로에서 figkit 은 모델을 부르지 않는다. 호출 LLM 이 이미 그림을 그렸고 figkit 은 측정과 정규화만 맡는다.

    python3 make_figure.py --name p1 --out out/p1 --svg p1.svg --brief p1_brief.md \
    [--data table.tsv] [--journal nature] [--width-pt 481.9] [--roundtrip]
    인자 뜻
    --svg 출고할 SVG. --name 폴더로 복사한 뒤 변환한다
    --brief 요청문. 여기서 mm 와 pt 수량만 읽어 SVG 와 견준다. 개체 이름이나 그림 종류는 읽지 않는다
    --journal 글자 하한과 캔버스 폭의 기준이 되는 저널 키
    --width-pt 루트 <svg> 에 mm, cm, in, pt 폭이 없을 때 쓸 물리 폭
    --data TSV 표. SVG 의 data-row 표식을 표와 대조한다(데이터 표식 규약)
    --roundtrip Illustrator 로 다시 열어 PDF 를 대조하는 선택 검사. Illustrator 가 없으면 SKIP 으로 기록한다

    나오는 파일¶

    --out 폴더에 <name>.svg, <name>.pdf, <name>-CAPTION.md, <name>.export.report.json 이 나온다. 보고서의 cost.calls 는 늘 0 이다.

    • fixed[] 는 figkit 이 고친 것이다. 항목마다 종류와 개수가 있다. 글꼴 목록을 SourceSans3 하나로 바꾼 것, <text> 마다 크기와 굵기와 색을 속성으로 적은 것, 숫자 굵기를 Regular 와 Bold 로 맞춘 것, 루트 mm 폭을 pt 로 바꾼 것, 도형 안 라벨을 세로 중앙으로 옮긴 것이 여기에 든다.
    • todo[] 는 호출 LLM 이 SVG 에서 고쳐야 하는 것이다. level 이 error 인 항목은 figure_lint 의 오류이고 글자 하한 미달, 알 수 없는 글꼴, 도형 여백 부족이 해당한다. --data 를 주면 보고서에 data_marks 가 들어가고 checks 에 실제로 비교한 항목이 적힌다. 불일치(data_marks)와 선언과 열의 어긋남(data_marks_input)은 level 이 error 인 todo 다.
    • level 이 check 인 항목은 요청 수량과 SVG 크기가 맞지 않는 경우이고 요청이 다른 치수를 말한 것일 수 있어 판단해서 무시해도 된다.

    종료코드¶

    코드 뜻
    0 level 이 error 인 todo 가 없다
    1 level 이 error 인 todo 가 남았거나 --roundtrip 이 실패했다. PDF 를 쓰지 못한 경우도 todo 로 올라 1 이다
    2 입력을 거부했다. viewBox 가 없다, 물리 폭이 없다, 그림 안에 한글이 있다, --data 표를 UTF-8 글자로 읽지 못한다

    호출 LLM 은 todo[] 를 고쳐 같은 명령을 최대 두 번 다시 돌린다.

    그릴 때 지킬 규칙¶

    처음부터 지키면 고칠 것이 줄어든다.

    • 글꼴 이름은 Source Sans 3 하나만 쓴다. 목록이나 대체 글꼴을 붙이지 않는다.
    • 모든 <text> 에 font-size, font-weight(normal 또는 bold), fill 을 속성으로 적는다. <style> 블록과 600 같은 숫자 굵기는 쓰지 않는다.
    • 루트에 width="170mm" height="44mm" viewBox="0 0 170 44" 처럼 mm 폭과 같은 비율의 viewBox 를 둔다. 글자는 최종 인쇄 크기에서 저널 하한(없으면 7 pt) 이상이어야 한다.
    • 도형 안 라벨은 도형 가운데에 두고 도형을 라벨보다 위아래로 2 pt 이상 크게 그린다.
    • 그림 안 글자는 영문이다.
