    데이터 표식 규약¶

    데이터 표를 SVG 위의 표식으로 그릴 때 호출한 모델이 아래 속성을 함께 적어 두면 figkit/data_marks_check.py 가 표 한 줄과 표식 하나가 맞는지 기계로 대조합니다. 속성은 그림의 모양을 바꾸지 않습니다.

    표 (TSV)¶

    첫 줄은 열 이름이고 탭으로 나눕니다. 파일은 UTF-8 이어야 하며 BOM 과 열 이름 앞뒤 공백은 무시합니다.

    열 필수 뜻
    row 아니오 행 키입니다. 없으면 머리글 다음 줄부터 1, 2, 3 으로 셉니다.
    x 아니오 표식의 데이터 위치입니다. 루트의 data-x-map 과 함께 있어야 합니다.
    lane 아니오 표식이 놓일 줄의 이름입니다. 표식이 data-lane 이나 루트가 data-lane-map 을 적으면 이 열이 있어야 합니다.

    row 값은 표 안에서 겹치면 안 됩니다. 숫자는 유한해야 하며 nan 과 inf 는 입력 오류입니다. 선언한 검사에 필요한 열이 없거나 열만 있고 선언이 없으면 조용히 건너뛰지 않고 입력 오류(종료 코드 2)로 끝납니다.

    SVG¶

    루트 요소에 위치 사상을 한 번 적습니다.

    <svg width="170mm" viewBox="0 0 170 60" data-x-map="12 0.8" data-lane-map="A:0:20 B:20:40">

    data-x-map="offset scale" 은 그린 x = offset + scale * 표의 x 를 뜻하며 단위는 SVG 사용자 단위입니다. 오차 0.5 pt 는 루트의 width 와 viewBox 로 pt 로 바꿔서 잽니다. 둘 중 하나가 없으면 사용자 단위 1 이 1 pt 입니다. 폭이 0 이하인 width 나 viewBox 는 입력 오류입니다.

    data-lane-map="lane:y0:y1 ..." 은 줄 이름마다 세로 대역(사용자 단위)을 선언합니다. 줄 이름에는 공백과 콜론을 쓸 수 없습니다. 선언하면 표식의 y 가 표의 lane 대역 안에 있는지까지 잽니다(lane-y). 선언하지 않으면 줄은 data-lane 문자열이 표와 같은지만 확인하며 위치는 확인하지 않습니다. 이 사실은 결과의 checks.lane ("label" 또는 "geometry") 과 CLI 출력에 그대로 적힙니다.

    표식은 표 한 줄마다 요소 하나이고 data-row 에 행 키를 적습니다.

    <circle cx="52" cy="20" r="1.5" data-row="r1" data-x="50" data-lane="A"/>
    • data-row 가 같은 요소는 표 한 줄에 정확히 하나여야 합니다. 없으면 missing 이고 둘 이상이면 duplicate 입니다. 표에 없는 키는 extra 입니다.
    • data-x 는 선택이며 적으면 표의 x 와 같아야 합니다(data-x 불일치). 표에 x 열이 없으면 입력 오류입니다.
    • data-lane 은 표에 lane 열이 있을 때 그 값과 같아야 합니다(lane 불일치).

    읽을 수 있는 표식¶

    표식 요소는 circle, ellipse, rect, line(세로선), text 만 읽습니다. 위치는 요소 자신의 속성에서 가져옵니다.

    요소 x y
    circle, ellipse cx cy
    rect x + width/2 y + height/2
    line x1 (x1 == x2 이어야 함) y1 과 y2 의 가운데
    text x y

    그 밖의 요소(path, g, use 등)에 data-row 를 달면 입력 오류입니다.

    조상 요소의 translate 는 더해서 읽습니다. 다음은 위치를 정할 수 없으므로 표식이 그 아래에 있으면 unsupported transform on mark 로 거부합니다.

    • translate 가 아닌 transform(scale, rotate, matrix 등)
    • style 속성 안의 transform
    • 루트가 아닌 중첩 <svg>
    • <style> 블록 안의 transform(블록 어디에든 transform 글자가 있으면 그리는 표식 전부를 거부합니다)
    • <defs>, <symbol>, <pattern>, <marker>, <clipPath>, <mask> 안

    CSS 클래스로 주는 변환은 읽지 않으므로 표식 쪽에는 쓰지 않습니다.

    그려지지 않는 표식¶

    display="none", visibility="hidden"(또는 collapse), opacity="0" 가 표식이나 그 조상에 속성이나 인라인 style 로 걸려 있으면 그려지지 않은 것으로 보고 세지 않습니다. 그 표식의 행은 missing 입니다. 클래스나 <style> 로 거는 숨김은 읽지 않으므로 쓰지 않습니다.

    실행¶

    python3 figkit/data_marks_check.py figure.svg table.tsv [--json]

    종료 코드는 0 이 일치, 1 이 불일치, 2 가 입력 오류(파일을 못 읽음이나 UTF-8 이 아님, 유한하지 않은 숫자, 선언과 열의 불일치, 지원하지 않는 표식이나 변환, 행 키 중복)입니다. 파이썬에서는 data_marks_check.check(svg_path, tsv_path) 가 {'rows', 'marks', 'matched', 'mismatches', 'ok', 'checks'} 를 돌려주고 입력 오류에는 DataMarksInputError(ValueError) 를 일으킵니다. mismatches 의 항목은 row, kind, msg 를 가지며 checks 는 실제로 비교한 항목(x 여부, lane 방식)을 알려 줍니다.
