    요청문과 원고에서 그림까지¶

    경로 B 는 글을 읽고 그림을 그린다. 입력은 필요한 그림의 설명(--brief, md 또는 txt)과 원고(--manuscript, md·txt·pdf) 가운데 하나 이상이다. 모델을 부르고 본인 Claude 계정의 사용량이나 비용이 든다. 이 경로는 --legacy-loop 를 줄 때만 돈다. 기본 경로는 호출 LLM 이 SVG 를 그리고 --svg 로 출고하는 것이다.

    먼저 dry-run¶

    --dry-run 은 준비물을 확인하고 원문을 조립하고 돌릴 명령을 찍는다. 모델을 부르지 않는다.

    python3 make_figure.py --name xyl --out out/xyl --legacy-loop --brief examples/make_figure/brief.md \
    --manuscript paper.pdf --section "Feedback" --journal nature --dry-run

    빠진 것이 있으면 [MISSING] 줄이 무엇이 빠졌고 어떻게 얻는지 적고 종료코드 2 로 멈춘다. 흔한 것은 Servier 아트 카탈로그다(설치). 모델에 보낼 글은 <name>.input.md 로 미리 볼 수 있다.

    문제가 없으면 같은 명령을 --dry-run 없이 돌린다.

    입력¶

    옵션 뜻
    --brief 필요한 그림의 설명(md, txt)
    --manuscript 원고(md, txt, pdf). PDF 는 pypdf 로 글자를 뽑는다
    --section <글자> 제목에 그 글자가 든 원고 절만 남긴다. 반복할 수 있다. 원고를 덜 보내는 방법이기도 하다
    --table <csv/tsv> 요청에 딸린 표. 표의 행마다 모델이 설명해야 하는 요청 항목이 된다
    --answers <md> 열린 질문의 답

    요청문 예시는 examples/make_figure/brief.md 다.

    # Figure request

One single-column schematic of a two-step pathway in a bacterial cell.

## Pathway

Enzyme XylA converts substrate S into intermediate I in the cytoplasm.
Enzyme XylB converts intermediate I into product P.
Product P represses the promoter of the xylAB operon.

## Emphasis

The repression by P is the point of the figure; draw it as the only inhibitory edge.

    그림이 무엇을 주장하는지, 등장 요소와 그 사이 관계, target 저널을 적어 두면 왕복이 준다.

    지원 장르¶

    경로 B 가 그리는 장르는 다섯이다. 계통수는 경로 A 의 --tree 단독 실행으로 그린다. --tree 와 --brief/--manuscript 를 섞으면 모델 호출 전에 종료코드 2 로 멈춘다. S1 이 장르를 tree 로 선언해도 작가 호출 전에 같은 안내로 멈춘다.

    호출 LLM 은 계통수 요청을 이 경로로 보내지 않고 Newick 과 필요한 표시 이름·분류표를 정리해 --tree 로 바로 실행한다. 입력 위상이 없을 때만 Newick 또는 위상 데이터를 요청한다. tree 안내의 rerun: 명령은 호출 LLM 이 실행하며 연구자에게 명령 입력을 넘기지 않는다.

    id 장르
    plasmid_map 플라스미드·컨스트럭트 지도
    edit_map 유전자별 편집(변이) 지도
    locus_comparison 유전자 좌위 비교
    pathway 구조식이 들어간 대사경로
    strain_design 균주 설계 도식

    면역·종양 만화, 세포 신호 만화, 임상 연구, 현미경·블롯 배치, 순서도·타임라인, 데이터 플롯, 지도, 동물 실험은 범위 밖이다. 모델이 요청을 범위 밖으로 읽으면 그리기 전에 열린 질문으로 멈춘다(종료코드 3). --out-of-scope-ok 를 주면 그래도 그리고 산출물에 범위 밖이라고 표시한다. 이때는 장르별 결정론 패널과 충실도 검사가 그 그림을 받치지 못한다.

    흐름¶

    1. S1: 원문을 읽고 무엇을 그릴지(content.yaml) 정한다.
    2. 열린 질문: 원문이 말하지 않는 곳이 있으면 비싼 그리기 단계 전에 멈춘다.
    3. 직접 저작 루프: 라운드마다 작가가 좌표를 쓰고 사전 검사 뒤 한 번 렌더하고 비평이 판정한다.
    4. 출고: 저널 폭으로 SVG 와 PDF 를 낸다.

    열린 질문¶

    S1 은 원문이 말하지 않는 곳(빠진 관계, 빠진 라벨, 추론한 내용)을 기록한다. 렌더러는 content 에 있는 것만 그리므로 이 자리는 그림의 빈틈이 된다. make_figure.py 는 S1 뒤에 이것을 질문으로 찍고 <name>.questions.md 와 답 템플릿 <name>.answers.template.md 를 쓴 뒤 종료코드 3 으로 멈춘다.

    • 답을 채워 --answers <name>.answers.template.md 로 다시 돌린다. 답이 원문의 한 절로 붙고 S1 이 다시 돈다.
    • 빈틈을 둔 채 그리려면 --accept-open 을 준다.

    요청이 데이터를 주지 않아 그릴 수 없는 요구(좌위가 하나만 등록됐는데 다섯 유전체 비교를 청한 경우 등)는 멈추지 않는다. <name>.questions.md 와 <name>.UNRESOLVED_TODO.md 에 무엇이 빠졌고 그림이 대신 무엇을 보이는지 적힌다.

    라운드와 예산¶

    옵션 뜻 기본값
    --rounds N 라운드 상한 1(초안 한 장)
    --budget-usd 작가 호출 하나의 USD 상한 12
    --total-budget-usd 실행 전체의 USD 상한. 남은 금액이 0.5 USD 이하면 새 호출을 시작하지 않는다 없음
    --author-effort 작가의 생각 강도(low, medium, high, xhigh, max) medium
    --author-max-output-tokens 작가 응답 하나의 출력 상한 32000
    --icons {auto,on,off} 단백질과 복합체를 아이콘으로 그릴지 off

    루프는 큰 결함(major)이 없고 결정론 검사가 모두 통과한 첫 라운드에서 멈춘다. 기본이 1 라운드인 까닭은 측정에서 2·3 라운드가 대부분의 그림에서 심사 판정을 바꾸지 못했기 때문이다. 남은 다듬기는 Illustrator 마무리에서 한다. 채택되지 않은 실행은 한 라운드 더 돌리는 명령을 찍는다.

    예산이나 라운드가 다해도 렌더된 라운드가 하나라도 있으면 가장 나은 라운드를 내보낸다. 왜 채택되지 않았는지는 <name>.UNRESOLVED_TODO.md 에 적힌다. 아이콘을 켜면 시간과 비용이 크게 는다.

    중단된 실행 이어 가기¶

    사용 한도 등으로 중간에 멈춘 실행은 같은 명령에 --resume 을 붙여 잇는다. 끝난 S1 과 라운드를 다시 쓰고 남은 라운드를 돈다. 요청문, 원고, 답, 표, 그리기 옵션이 앞 실행과 다르면 무엇이 다른지 밝히고 거절한다.

    데이터 패널을 함께 넣기¶

    --panel 을 더하면 패널을 구조화 입력으로 등록하고 작가가 그림 안에 배치한다. 충실도 검사가 등록한 입력이 모두 배치됐는지 본다.

    python3 make_figure.py --name xyl_fig --out out/xyl_fig --legacy-loop --brief examples/make_figure/brief.md \
    --panel examples/make_figure/yield.panel.yaml

    이미 fig.yaml 이 있으면 --mech-spec <fig.yaml> 로 모델 없이 기전 그림 아래에 데이터 패널을 붙인다.

    산출물¶

    파일 내용
    <name>.svg, <name>.pdf 그림. PDF 를 직접 열어 겹침, 잘림, 사라진 글자를 본다
    <name>-CAPTION.md 캡션 사이드카. 패널 출처, 아트 저작자 표시, AI 사용 고지 한 문장
    <name>.input.md 모델에 보낸 조립 원문
    <name>.report.json 실행 명령, lint, 비용, 상태(status)
    <name>.evidence.md, <name>.claims.json 근거 보고서
    <name>.questions.md 열린 질문
    <name>.UNRESOLVED_TODO.md 해결되지 않은 것: 요청이 데이터를 주지 않은 요구, 통과하지 못한 검사, 비평의 major

    SVG 에는 도구 판, 시각, 입력 파일 해시, 결정론으로 그린 것과 모델이 한 것을 적은 출처 기록이 들어 있다.

    상태 읽기¶

    report.json 의 status 가 실행의 끝을 말한다. 종료코드 0 만으로 최종본이라 판단하지 않는다.

    status 뜻
    accepted 검토를 통과한 라운드다
    best_round_exported 라운드가 다해 가장 나은 라운드를 내보냈다
    budget_stop_exported 예산 상한에 걸려 가장 나은 라운드를 내보냈다. 채택이 아니다
    timeout_stop_exported 호출이 시간 초과로 멈췄다. --resume 으로 그 라운드를 다시 한다
    failed_no_passing_round 렌더된 라운드가 없다. 종료코드 1
    stopped_open_questions 열린 질문으로 멈췄다. 종료코드 3

    근거 보고서¶

    그림에 그려진 사실 하나가 한 행이다. 행마다 그 사실을 그린 SVG 요소, 요청 줄, 출처, 근거 등급, 기계 확인 결과가 있다. 근거 없는 사실은 맨 위 「Look at first」 에 모인다.

    등급 뜻
    literature 요청이 단 DOI, 웹 주소, 파일
    database GenBank·UniProt 기록이나 PubChem 구조 일치
    user_data 사용자가 준 표나 파일의 값과 대조됨
    cited_unverified 출처를 달았으나 확인되지 않음
    inferred 원문에 없다고 표시됨
    none 근거 없음

    출처는 요청에 ## Sources 절을 두어 단다.

    ## Sources

[S1] doi:10.1021/acs.jafc.3c00286
[S2] genbank:NC_002977.6
[S3] uniprot:P53602
[S4] file:data/paper.pdf

    본문 사실 옆에 [S1], [S4 p.3], [S1, S2 p.4] 처럼 꼬리표를 붙이면 그 줄의 사실이 그 출처를 근거로 갖는다. DOI 는 Crossref 로, GenBank·RefSeq 는 NCBI 로, UniProt 은 UniProt 으로 존재와 철회 여부 등을 확인한다. file: 경로는 요청 파일이 있는 폴더 기준이다.

    • --require-sourced: 근거 없는 사실이 있으면 그림과 보고서를 쓴 뒤 종료코드 6 으로 끝난다.
    • --offline: 네트워크 조회를 하지 않는다. 확인 결과는 UNVERIFIED(no network) 로 남는다. 그림은 같다.

    이미 그린 그림에는 python3 mech/claims.py <out 폴더> <name> 로 같은 두 파일을 다시 만든다.

    무엇이 밖으로 나가나¶

    • 조립 원문 <name>.input.md(그림 설명, 원고 문단, 답)와 규칙 문서를 실행한 사람의 Claude 계정으로 보낸다. 비평 단계는 렌더한 PNG 도 본다.
    • 구조식이 있는 대사체 이름을 PubChem 에, ## Sources 의 식별자를 Crossref, NCBI, UniProt 에 묻는다. --offline 이면 묻지 않는다.

    종료코드¶

    코드 뜻
    0 끝났다. status 를 함께 본다
    1 한 단계가 실패했다
    2 입력이나 준비물이 없다. 메시지가 무엇을 어떻게 얻는지 적는다
    3 열린 질문이 있어 그리기 전에 멈췄다
    6 --require-sourced 를 줬고 근거 없는 사실이 있다
