    비용과 시간¶

    경로 B 는 실행한 사람의 Claude Code 로그인으로 돈다. 아래 USD 는 Claude Code 가 보고하는 API 정가 환산값이다. API 키로 쓰면 이 금액이 청구되고 Claude 구독(Pro, Max)으로 로그인했으면 따로 청구되지 않고 구독 사용 한도를 쓴다.

    값은 과거에 주제 하나씩 잰 것이다. 현재 실행의 견적이 아니며 주제와 그림 크기에 따라 달라진다.

    무엇 비용 시간
    S1, 글로 쓴 그림 설명 입력 1.75 USD 261 초
    그리기 1 라운드의 작가 호출 4.37 USD 11 분
    기전 그림 한 장, 3 라운드 12.41~20.80 USD 33~65 분
    기전 그림 한 장, 2 라운드에서 멈춤 9.93 USD 26 분
    데이터 그림 0 2 초 안팎

    1.1.0 판 기준으로 경로 B 한 장은 요청과 라운드 수에 따라 12~21 USD, 30~65 분이 든다. 아이콘을 켜면(--icons auto) 한 요청에서 시간과 비용이 두 배를 넘었다.

    비용을 묶는 방법¶

    • --rounds 기본값이 1 이다. 더 돌릴 때만 올린다.
    • --total-budget-usd 로 실행 전체의 상한을 건다. 호출 하나가 상한을 넘는 만큼은 초과할 수 있다.
    • --budget-usd 로 작가 호출 하나의 상한을 건다(기본 12).
    • 실행이 끝나면 make_figure.py 가 호출 수, 비용, 시간을 합쳐 찍고 <name>.report.json 에 남긴다.

    같은 요청을 두 번 부르지 않기¶

    모델을 부르기 전에 공유 결과 캐시를 본다. 요청 지문이 같은 채택 산출이 캐시에 있으면 모델을 부르지 않고 그 산출을 쓴다(비용 0). 기본 캐시는 ~/.cache/figkit 다. 팀이 나누려면 FIGKIT_CACHE 를 공유 폴더로 두고 같은 판, 같은 도판 이름, 같은 원문 상대 경로를 쓴다.

    결정론인 것과 아닌 것¶

    같은 입력이면 같은 바이트 돌릴 때마다 다를 수 있다
    데이터 패널, 유전체 패널, 계통수 패널 S1 이 정한 내용
    렌더, 출고, 합성 작가의 좌표, 형태, 아트 선택
    사전 검사, figure_lint, 인용 검사 비평의 판정
