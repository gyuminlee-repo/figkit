    Illustrator 마무리¶

    make_figure.py 가 낸 SVG 를 Claude 가 Illustrator 로 들여 배치와 타이포그래피를 다듬고 최종 <figure>_ai_finished.ai 와 <figure>_ai_finished.pdf 를 낸다. 파이프라인은 여기서 끝난다. 연구자가 Illustrator 를 조작하지 않는다.

    준비¶

    • Adobe Illustrator(Windows 또는 macOS)
    • Claude Code 에 등록한 Illustrator MCP(설치)
    • Illustrator 에 열린 문서가 없을 것

    플러그인을 켠 세션에서 이렇게 말한다.

    out/xyl/xyl.svg 를 Illustrator 에서 마무리해

    여기서 고치는 것과 돌려보내는 것¶

    make_figure 로 돌려보낸다 여기서 고친다
    내용이 빠졌거나 틀린 것: 표의 행, 구조, 유전자 이름, 다시 그려야 하는 패널, 범례와 다른 뜻으로 읽히는 색 배치와 타이포그래피: 요청에 없는 요소 제거, 제목이나 범례 이동, -> 를 → 로 교체, 범례 표지 추가, 대지 자르기

    SVG 가 캔버스 밖으로 잘라 낸 기하는 Illustrator 에서 되살릴 수 없다. 요청문을 고쳐 다시 그린다.

    반입¶

    1. 열린 문서가 없는지 확인한다. 열린 문서가 있으면 멈추고 알린다.
    2. SVG 크기 그대로 새 문서를 만든다.
    3. SVG 를 편집 가능한 상태로 들인다. 글자는 텍스트 프레임으로, 도형은 패스로 들어온다.
    4. 화살표를 선 속성 화살촉으로 바꾼다. SVG 의 화살표는 선과 삼각형 두 도형이라 그대로 두면 선을 옮길 때 머리가 따라오지 않는다. 바꾼 뒤에는 선을 옮기거나 굵기를 바꿔도 촉이 붙어 다닌다.

    Windows 의 Illustrator 를 WSL 에서 부를 때는 SVG 를 Windows 에서 보이는 폴더로 먼저 복사한다. 폴더는 사용자가 정한다.

    편집 가능한 텍스트¶

    글자는 Source Sans 3 하나로 들어온다. Illustrator 는 font-family 목록에서 글리프 단위 폴백을 하지 않으므로 figkit 은 글꼴 이름을 하나만 쓴다.

    • 이탤릭과 정체가 섞인 라벨(속명·종명은 이탤릭, sp., 균주 이름은 정체)은 한 프레임 안에서 글자별로 글꼴을 바꿀 수 없어 프레임을 나눠 같은 baseline 에 둔다.
    • 마무리를 마치기 전에 그림 안 모든 글자에서 속명, 종명, 유전자 기호가 이탤릭인지 따로 훑는다.
    • 기호를 아웃라인화할지는 출고 직전에 묻는다. 편집 가능성과 이식성의 맞바꿈이다.

    왕복 확인¶

    저장하기 전에 글자를 대조한다. Illustrator 의 텍스트 프레임 목록을 원래 SVG 의 글자와 견줘 사라진 글자(MISSING)와 바뀐 글자(CHANGED)를 찾는다.

    python3 figkit/text_inventory.py <figure>.svg --after <figure>_frames.json --edits finishing_record.json

    사라지거나 바뀐 줄은 하나하나 적어 둔 편집과 맞아야 한다. 설명되지 않는 줄이 있으면 저장하지 않고 글자를 되살린다.

    저장과 출고 뒤에는 이렇게 확인한다.

    • 내보낸 PDF 를 열어 렌더된 쪽을 요청과 견준다. 추출된 글자가 아니라 쪽의 모양을 본다.
    • pdffonts <PDF> 로 모든 글꼴 행이 emb=yes 인지 본다.
    • 마무리 기록(편집 목록, 글자 대조 요약, 화살표 적용 수)을 근거 보고서에 덧붙이고 최종 PDF 옆에 같은 보고서를 둔다.

    안전¶

    • Claude 는 이 그림을 위해 새로 만든 문서에서만 일한다. 사용자 문서는 닫지도 저장하지도 고치지도 않는다.
    • 사용자가 준 .ai 는 덮어쓰지 않고 새 이름으로 저장한다.
    • Illustrator 창은 켠 채 다른 창 뒤에 둔다. 글꼴 누락 같은 대화상자가 뜨면 스크립트가 멈추는데 창이 최소화돼 있으면 그 대화상자가 보이지 않는다. 작업 중에는 Illustrator 창 안을 클릭하거나 문서를 열고 닫지 않는다.
    • 최소화가 필요하면 ILLUSTRATOR_MCP_MINIMIZE=1 을 둔다.

    BioRender 아이콘¶

    BioRender 에서 PDF 로 받은 아이콘은 마무리 단계에서 그 도판 하나에만 손으로 놓는다. 색은 BioRender 에서 정한다. PDF 안의 아이콘은 래스터라 Illustrator 에서 색을 바꿀 수 없다. Created with BioRender.com 표기와 publication license 가 따로 필요하다. 사용이 요금제의 출판 조건을 만족하는지는 사용자가 확인한다.
