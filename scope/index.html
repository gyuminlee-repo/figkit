    범위와 알려진 한계 (1.1.0)¶

    쓸 수 있는 것¶

    경로 A 전부(데이터 패널, 유전체 지도, 변이 패널, 표, 계통수 패널)와 경로 B 의 대사경로·유전자 클러스터 도판이다. 경로 B 의 이 두 장르는 처음 보는 논문 한 편씩을 그려 충실도 FAIL 0 으로 통과했다. Illustrator 2026 왕복은 경로 A 데이터 패널과 경로 B 출고물 모두 통과했다.

    실험 기능¶

    경로 B 의 일반 기전도는 회귀 검사와 예제로만 확인했다. 처음 보는 요청으로 시험한 적이 없으므로 결과를 직접 검수한다. 경로 B 한 장은 요청과 라운드 수에 따라 12~21 USD, 30~65 분이 든다(비용과 시간).

    알려진 한계¶

    • --tree 로 계통수를 모델이 그리게 하는 경로는 처음 보는 논문 시험에서 통과하지 못했다. 충실도 FAIL 은 0 이었지만 직접 검수에서 가리킬 대상이 없는 범례, 끊긴 말단, 넓은 빈 영역, 중복 라벨이 나왔다. 계통수가 필요하면 경로 A 의 계통수 패널(tree_table, tree_matrix)을 쓴다.
    • 충실도 검사는 요청한 항목이 그림에 있는지를 본다. 배치 품질(빈 영역, 중복 라벨)은 직접 검수로 확인한다.
    • 큰 계통수(말단 약 80 개 이상)는 page_aspect lint 경고가 남는다. 크기 정책은 정하지 않았다.
    • 이 판의 자동 CI 는 꺼져 있다. 출고 전 검증은 로컬 검사로 했다.

    그 밖의 경계¶

    • 그림 안 글자는 영문이다. 한글은 캡션에 쓴다.
    • Illustrator 마무리는 Windows 와 macOS 에서 지원한다. WSL2 는 Windows 의 Illustrator 를 부르는 호환 브리지다. 순수 Linux 는 지원하지 않는다.
    • BioRender 자산은 플러그인에 들어 있지 않고 엔진이 자동으로 배치하지 않는다.
